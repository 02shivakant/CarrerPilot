# CareerPilot Frontend

React + Vite starter for the CareerPilot project.

## Setup

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Included

- React + Vite setup
- Axios, React Router, and Lucide React dependencies
- Starter CareerPilot page
- Organized `src` folders for components, pages, layouts, services, context, and hooks

This is the frontend starter scaffold; authentication, dashboard pages, and Django API integration will be implemented in the next development steps.
